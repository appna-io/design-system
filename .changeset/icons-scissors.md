`@apx-ui/icons`: add `Scissors` — open shears for barbers, salons, grooming menus
and trim / cut actions. Added for the Fade & Co. barbershop template, which had no
glyph in the set for the one thing the business does. Exported from the package
root and registered in `ICON_MANIFEST` (kept alphabetical), so it shows up in the
renderer's `/icons` gallery with the rest.
